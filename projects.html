Project ideas

Stuck for a capstone topic?

Here are starter concepts — each can scale from a semester project to a full capstone:

GPS + LoRa + BLE beaconing. Track laptops, tools, lab carts. Dashboard with geofence alerts.

Camera + Jetson + YOLO. Detect missing components, solder bridges, wrong orientation. PLC integration for reject.

Implement secure boot, key storage, and attestation on a RISC-V core with PUF. Formal verification of boot ROM.

Count/classify vehicles at intersection. Model runs on edge box; aggregates to cloud for signal timing optimization.

UR5e + gripper + vision. Pick-and-place SMD components. Safety-rated monitored stop, force limiting.

Extend VexRiscv or Ibex with a tensor accelerator. Verify with formal methods. Tape-out via Efabless/OpenMPW.
Competition-ready tracks

Align your project with these annual contests:

  • Philippine Robotics Olympiad — line follow, sumo, humanoid, innovative
  • ICPC Asia Regional — algorithmic programming (teams of 3)
  • Hackathons — UE CodeCpE, DOST-SEI, IEEE, corporate (Intel, Analog Devices)
  • Chip Design — Efabless Open MPW Shuttle, Google LFP
  • Cybersecurity CTF — PWN, RE, Crypto, Hardware (IEEEXtreme, local)
  • Data Science — Kaggle, DOST-PCIEERD, Analytics Philippines
