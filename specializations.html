Specialization Tracks in Computer Engineering

Nine focus areas — pick a path, build deep expertise, and keep your options open.

Note: These tracks reflect the typical breadth of a BS CpE program (Philippine CHED-aligned). Specific electives, lab offerings, and research directions vary by campus and semester. Confirm current options with the College of Engineering.
9 specializations shown
Embedded Systems

Design firmware for microcontrollers and SoCs that run under tight constraints of power, memory, and real-time deadlines.

  • RTOS, bare-metal C/C++
  • Peripheral drivers (I²C, SPI, UART)
  • Power management & sleep modes
C FreeRTOS ARM Cortex-M

Career path: Firmware Engineer, Embedded Software Engineer, IoT Device Developer

Internet of Things (IoT)

Connect sensors and actuators to networks — from smart-home nodes to industrial telemetry.

  • Wireless protocols (BLE, LoRa, Zigbee, Wi-Fi)
  • Edge gateways & MQTT/CoAP
  • Sensor fusion & data pipelines
ESP32 MQTT Node-RED

Career path: IoT Solutions Architect, Embedded Connectivity Engineer, Smart Systems Integrator

Computer Networks

Design, configure, and troubleshoot the infrastructure that moves data — LAN/WAN, data centers, and carrier networks.

  • Routing, switching, VLANs, VPNs
  • TCP/IP, BGP, MPLS, QoS
  • Network automation (Ansible, NetBox)
Cisco Juniper Linux

Career path: Network Engineer, Systems Engineer, Network Automation Engineer

Cybersecurity

Protect hardware and software systems — from secure boot and side-channel analysis to network defense and incident response.

  • Secure firmware, TPM, HSM
  • Network monitoring, IDS/IPS, SIEM
  • Vulnerability assessment & hardening
Wireshark Burp Suite YARA

Career path: Security Engineer, Embedded Security Researcher, SOC Analyst, Penetration Tester

AI / Machine Learning

Deploy ML models on edge devices, optimize inference for constrained hardware, and build hardware-aware training pipelines.

  • Model quantization, pruning, distillation
  • TensorRT, TFLite, ONNX Runtime
  • Computer vision & sensor analytics
Python PyTorch TensorRT

Career path: ML Engineer (Edge), Computer Vision Engineer, AI Accelerator Engineer

Data Engineering

Build pipelines that ingest, transform, and serve high-volume sensor and system data for analytics and ML.

  • Streaming (Kafka, Flink), batch (Spark)
  • Time-series DBs (InfluxDB, TimescaleDB)
  • Data quality, schema evolution
SQL Kafka Airflow

Career path: Data Engineer, Platform Engineer, Streaming Systems Engineer

Robotics & Control

Integrate sensing, actuation, and real-time control — from mobile robots to industrial automation.

  • ROS 2, PID, state estimation
  • Kinematics, path planning, SLAM
  • Safety-critical real-time loops
ROS 2 C++ Gazebo

Career path: Robotics Software Engineer, Control Systems Engineer, Automation Engineer

Computer Architecture

Design and analyze processor microarchitecture, memory hierarchies, and accelerators for performance and efficiency.

  • Pipeline design, branch prediction, caches
  • RISC-V, ARM, custom accelerators
  • Hardware description (Verilog, Chisel)
Verilog RISC-V gem5

Career path: CPU Architect, RTL Design Engineer, Verification Engineer, Performance Engineer

Cloud & Edge Computing

Distribute workloads between cloud and edge — container orchestration, serverless, and low-latency offload.

  • Kubernetes, K3s, KubeEdge
  • eBPF, service mesh, observability
  • Edge AI inference, 5G MEC
Kubernetes Go eBPF

Career path: Platform Engineer, Cloud Infrastructure Engineer, Edge Computing Specialist

Choosing a track

You don't have to pick just one

Many CpE graduates work across boundaries. A firmware engineer who understands networking builds better IoT devices. A network engineer who knows ML can deploy anomaly detection on the wire. The core curriculum gives you the shared vocabulary; electives and projects let you go deep.

  • Start with a capstone project that spans two areas (e.g., embedded + ML).
  • Take one elective outside your comfort zone each semester.
  • Join SCPES workshops — they often cross tracks.
  • Build a portfolio that shows breadth and depth.
