## Images

Place your images inside `assets/` and update the `src`/`alt` in `index.html` (hero, profile, and three projects).

The template includes a visual fallback for missing images, so the layout will still look intentional if an image has not been added yet.

## Customize

1. Replace the sample bionote text in `index.html`.
2. Add your actual project images to `assets/`.
3. Replace the social links with your URLs.
4. Replace the sample email address.
5. Adjust the colors and typography in `css/variables.css` and `css/base.css`.

## Deploy

The repo root deploys directly (GitHub Pages: deploy from branch root). Edit files, commit, push — there is no build step and no JavaScript.
